# CRCI Android App

A minimal Jetpack Compose Android application that consumes the `crci-core` FFI bindings generated by UniFFI.

## Prerequisites
- Android Studio Jellyfish or newer
- NDK r26+ installed via SDK Manager
- Rust toolchain with targets:
    ```sh
    rustup target add aarch64-linux-android x86_64-linux-android
    ```

## Building the native library
```sh
cargo ndk -t arm64-v8a -t x86_64 \
  -o crci-android/app/src/main/jniLibs \
  build -p crci-core
```

## Running
1. Copy .so files as above (or via standard cross-compilation pipeline).
2. Open `crci-android/` in Android Studio.
3. Run on emulator (x86_64) or device (arm64-v8a).

## Note on generated bindings
The Kotlin FFI bindings in `app/src/main/kotlin/dev/crci/android/ffi/`
are generated from `crci-core` via UniFFI (Session 53).
To regenerate: `bash bindings/kotlin/generate.sh`
