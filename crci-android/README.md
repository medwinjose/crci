# CRCI Android App

A minimal Jetpack Compose Android application that consumes the `crci-core` FFI bindings generated by UniFFI.

This app demonstrates how a mobile edge client can participate natively in the CRCI mesh network. Instead of communicating through a web server, the app links directly to the `crci-core` Rust library via the `dev/crci/android/ffi/` Kotlin bindings, allowing it to evaluate local reputation, perform cryptographic signatures, and broadcast emergency telemetry securely.

## Prerequisites
- Android Studio Jellyfish or newer
- NDK r26+ installed via SDK Manager
- Rust toolchain with targets:
    ```sh
    rustup target add aarch64-linux-android x86_64-linux-android
    ```

## Building the native library
```sh
cargo ndk -t arm64-v8a -t x86_64 \
  -o crci-android/app/src/main/jniLibs \
  build -p crci-core
```

## Running
1. Copy `.so` files as above (or via standard cross-compilation pipeline).
2. Open `crci-android/` in Android Studio.
3. Run on emulator (x86_64) or device (arm64-v8a).

## FFI Bindings Pipeline
The Rust core is exposed to Kotlin via UniFFI.
- The Rust macro definitions live inside `crates/crci-core`.
- The UniFFI generator produces the Kotlin interface at `crci-android/app/src/main/kotlin/dev/crci/android/ffi/`.
- To manually regenerate these bindings after modifying the `crci-core` API, run:
  ```bash
  bash bindings/kotlin/generate.sh
  ```
